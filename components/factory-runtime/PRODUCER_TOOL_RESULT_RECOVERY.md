# Producer and role tool-result recovery
Shared disk is the only state and completion evidence. `sessions_list`, `sessions_send`, chat replies, and session trees are forbidden as infrastructure or completion proof. Every role first writes a local read/write/exec probe receipt. A missing, empty, malformed, or unbound Agent tool result causes only that role to write `ROLE_TOOL_CHANNEL_BLOCKED`, retain the same running task/work-item/checkpoint/dispatch/run/fence/cursor, and back off. The next tick resumes from disk. Producer only schedules files and is never a global coordinator or single point of failure. The other four locks/processes continue independently.
